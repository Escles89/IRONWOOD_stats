# Quick Loot and Skills

**Quick Loot** and **Skills** are adjacent icons in the **Current Loot** header. When compact crafting hides that card, the icons sit at the right end of the crafting information bar. On native skill pages Quick Loot appears only beside Stop & Loot for the exact running skill and action, with equal button widths and matching native styling. When browsing an inactive action, only Skills appears after the native start controls; Amount and Craft remain together. Quick Loot uses a text label there; Skills keeps its grid icon. Other native pages keep them beside the sidebar’s current-action area.

The Skills control uses a grid icon. Inside the modal, skills show their current level from the native sidebar beside their name (Taming has no skill level). Each regional skill shows its region icon beside its name, with the region name on hover. Defense uses the equipped weapon’s region when available; otherwise it shows all three regions. Taming has its separate expedition system. Each levelled skill also shows its XP within the current level, the XP required for the next level, and a progress bar. Time to the next level uses the game’s XP estimate for the current or remembered action with your current equipment and bonuses. Inactive skills label this “If started”; skills without an available rate show a dash. Estimates assume continuous training, so a finite queue ending or a bonus expiring can change the actual time. Hover the compact XP bar or percentage for exact earned/required XP; hover the time estimate for the XP rate and assumptions.

The Skills icon opens a centered modal, styled like the Guide, with native skill icons. **Skills** lists every skill in the game's navigation order. Status remembers the last action it observes actually running for each skill, across visits to this browser. **Start** starts that named action; Click anywhere on a skill card to open its native page and choose something else. The Start and amount buttons keep their separate actions. Browsing does not replace the remembered action. The current action is labelled **Current**. Taming provides its native page shortcut because expeditions use a separate activity model.

History and configured quantities are separate for each character and solo mode. If Status cannot identify the character or read the native action requirements, it explains the limitation instead of starting an uncertain target.

Gathering skills have no configured amount, including Farming even though it consumes Seeds and Compost. Their remembered actions start through the native gathering control. Crafting amount dialogs show the selected recipe's item icon and identify both its skill and action.

Finite activities use a native-style chooser with Owned, Craftable and Estimated Time rows. **Craft** uses the entered quantity, **Craft All** uses the available supply, and **Target** crafts the difference between your entered inventory total and what you already own. The estimate uses the game’s calculation when available. **Reuse this configured amount** is always visible and checked by default for new recipes; uncheck it to keep choosing a quantity each time. Existing saved choices are respected. **Edit amount** remains available. When supplies cannot cover the configured amount, the prompt shows the current maximum, including secondary resources. A smaller one-time choice leaves the configured amount unchanged unless you check **Replace my configured amount**. Cancelling before a start leaves the current action untouched.

Start is a manual action and works with background automation disabled. Ironwood's native start workflow handles collecting the old action and starting the target; Status keeps your original page open. Conflicting quick actions and cache refreshes wait until the request is finished.

The recap separates the action result from collected rewards. A failed start can leave you idle after successful collection. Missing reward details or a later synchronization error do not imply that the start failed. Check the current action before retrying an unconfirmed request; Status never automatically retries or rolls back a switch.

Quick Loot retains its automation preference and collects before continuing the same action, including a finite queue's remaining quantity. Its button stays visible when disabled and explains why. Use Tab to move through the panel and Escape to dismiss it; focus returns to Skills.
