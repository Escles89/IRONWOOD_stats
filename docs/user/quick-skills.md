# Quick Loot and Skills

Click a non-interactive area at the top of the **Current Action** panel to open Skills. The Materials and Consumables sections are excluded. Existing consumable, mastery and action controls keep their own behavior. The panel also opens with Enter or Space when focused, including while idle.

**Skills** also has its own page directly beneath **Status** in the sidebar, marked with the game's pixel-art tome. It shows the same skill list, leaderboard ranks, remembered actions and planner as the modal. Start and Edit open their usual quantity dialogs over this page. You can bookmark `/skills`, reload it, or use browser Back and Forward between Skills, Status and native pages.

**Quick Loot** and **Skills** are adjacent icons in the **Current Loot** header. When compact crafting hides that card, the icons sit at the right end of the crafting information bar. On native skill pages Quick Loot appears only beside Stop & Loot for the exact running skill and action, with equal button widths and matching native styling. When browsing an inactive action, only Skills appears after the native start controls; Amount and Craft remain together. Quick Loot uses a text label there; Skills keeps its grid icon. Other native pages keep them beside the sidebar’s current-action area.

The Skills control uses a grid icon. On both the page and modal, skills show their current level from the native sidebar beside their name. Each regional skill shows its region icon beside its name, with the region name on hover. Defense uses the equipped weapon’s region when available; otherwise it shows all three regions. Each levelled skill also shows its XP within the current level, the XP required for the next level, and a progress bar. Time to the next level uses the game’s XP estimate for the current or remembered action with your current equipment and bonuses. Inactive skills label this “If started”; skills without an available rate show a dash. Estimates assume continuous training, so a finite queue ending or a bonus expiring can change the actual time. Hover the compact XP bar or percentage for exact earned/required XP; hover the time estimate for the XP rate and assumptions.

Each skill also shows its leaderboard rank in a compact trophy badge attached to the upper-right edge of its row for your current game mode. Ranks are checked when Skills opens and cached for one hour, including across reloads. The panel refreshes them only while open and visible. Hover a rank for its last check time. **Unranked** means the loaded leaderboard has no entry for your character; **Rank —** means data is unavailable. If a refresh fails, last known ranks remain visible with a **cached** label and retry after five minutes.

The Skills icon opens a centered modal, styled like the Guide, with native skill icons. **Skills** pins your active skill and compact planner at the top, then lists the remaining action skills in the game's navigation order. Status remembers the last action it observes actually running for each skill, across visits to this browser. **Start** starts that named action; click anywhere on a skill row to open its native page and choose something else. Compact Start and Edit controls sit together beneath the rank badge and keep their separate actions. Action buttons use the same sizing throughout the portal. Browsing does not replace the remembered action. The active row is labelled **Current action** and includes **Stop & Loot**. This stops the action and collects pending loot without restarting it, and pauses any automatic recipe plan. It works with background automation disabled. The row returns to its normal position once you are idle. Taming is omitted from this menu; its expeditions remain available through the native sidebar and Status.

History and configured quantities are separate for each character and solo mode. If Status cannot identify the character or read the native action requirements, it explains the limitation instead of starting an uncertain target.

Gathering skills have no configured amount, including Farming even though it consumes Seeds and Compost. Their remembered actions start through the native gathering control. Crafting amount dialogs show the selected recipe's item icon and identify both its skill and action.

Finite activities use a native-style chooser with Owned, Craftable and Estimated Time rows. **Craft** uses the entered quantity, **Craft All** uses the available supply, and **Target** crafts the difference between your entered inventory total and what you already own. The estimate uses the game’s calculation when available. **Always use max** is selected by default in the first quantity prompt for a recipe. Confirm it to reuse a freshly calculated maximum on subsequent starts. Uncheck it to enter a fixed amount; also uncheck **Reuse this configured amount** to choose a quantity each time. Existing saved choices are respected. **Always use max** saves a per-recipe preference to recalculate the largest craftable quantity on each manual Start, including secondary resources. It enables reuse and skips the quantity prompt; it does not start recipes automatically or change Quick Loot’s remaining queue. **Craft All** / **Use max** alone uses today’s maximum as a fixed quantity. **Edit amount** remains available, and **Save amount** always saves the edited choice without starting an action. When supplies cannot cover a fixed configured amount during Start, a smaller one-time choice leaves it unchanged unless you check **Save this as my new configured amount**. That checkbox appears only in the shortage prompt, never in the editor. Cancelling before a start leaves the current action untouched.

Start is a manual action and works with background automation disabled. Ironwood's native start workflow handles collecting the old action and starting the target; Status keeps your original page open. Conflicting quick actions and cache refreshes wait until the request is finished.

The recap separates the action result from collected rewards. A failed start can leave you idle after successful collection. Missing reward details or a later synchronization error do not imply that the start failed. Check the current action before retrying an unconfirmed request; Status never automatically retries or rolls back a switch.

Quick Loot retains its automation preference and collects before continuing the same action, including a finite queue's remaining quantity. Its button stays visible when disabled and explains why. Use Tab to move through the panel and Escape to dismiss it; focus returns to Skills.

**Recipe Calc & planner** opens the combined calculator and recipe plan over the current page. A compact summary beside the active skill on wide layouts, or below it on narrow screens, shows the planner state, next action and **Start next**. A separate **Recipe planner** panel below the skills list contains the full status, controls, target, remaining requirements, owned quantities and shortages. **Planner** or **Edit plan** opens the full editor. See [Recipe plans](recipe-plan.md) for source choices, explicit collection and manual requirements.
