# Recipe Calc and recipe plans

Open **Skills → Recipe Calc & planner**, or select **Edit** on the Status Recipe Calc card. The combined panel opens over the page you are using.

The panel has three views: **Active plan**, **Calculator**, and **Single action**. It opens on your active plan when one exists.

In **Calculator**, choose a finished item and its **Target owned quantity**, then select **Save & run plan**. Saving updates the active recipe plan, enables automatic progression, and returns to Active plan. **Edit** starts from the active recipe, including its source and conversion choices; **Cancel** discards unsaved target and input edits. There is no separate Send to planner step.

Select **Inputs** while editing to choose Potion Mix, Metal Parts, Arcane Powder gems, and trees/wood for Charcoal. Dropdowns show the conversion yield and owned quantity: green means some stock is owned, red means none is owned, and amber means the balance is unknown. Green does not mean there is enough for the whole recipe. Pending loot is excluded. The selected dropdown and its options use these colors; colored stock markers and owned quantities also appear on systems that draw option menus in their own colors.

A selected input appears as an item icon beneath its resource when more of that resource is needed. The tree stops at any item or resource fully covered by owned stock, hiding its unused ingredient chain. Covered resources consume no input stock. Charcoal and Arcane Powder default to combining spare owned wood or gems after reserving items needed by other recipes. Higher-yield types are used first. The tree shows only the two highest-yield allocated types, while estimates and line colors still include every allocated input. The automatic-input lines are green when the full pool covers the requirement, blue when more is needed, and amber when coverage is unknown. Open the resource details for the complete breakdown. Selecting a specific wood or gem uses only that type and includes any missing inputs in the plan. Both resources also offer **Use resource balance only**, which counts only the existing Charcoal or Arcane Powder balance and excludes conversion inputs. Choose **Use spare owned wood automatically** or **Use spare owned gems automatically** to return to mixed inputs. Each choice is saved with the plan. These conversions remain manual inventory actions.

Status keeps one compact Recipe Calc card with the recipe tree and a short **Planned** overview. The overview shows up to three remaining requirements, including the next action and work already in progress. Open the full planner through Skills for action controls and the complete list.

Both the Skills page and modal show your current action and a compact plan summary with **Start next** side by side when each has at least 360 px of space. They stack on narrow screens; when idle, the summary fills the row. A separate **Recipe planner** panel below the skills list shows full requirements. The summary shows one **Next** action for the plan. The active plan shows compact requirement rows with Next, Ready, Blocked or Manual badges. Expand a row to see required, owned and missing amounts, batch supplies, quantity controls and source choices; **Choose … next** selects another ready step. Conversions and other manual requirements include an inventory link. Opening that link does not complete the requirement: the resulting balance must be observed.

**Automatic plan** starts ready gathering and crafting steps, collects their output when due, and recalculates before starting the next step. Finite crafting is due when its native output limit is reached; continuous gathering is due when known pending loot covers the remaining requirement. Estimated time alone never triggers collection. Saving or resuming can follow a matching recipe action already running; unrelated work is left for you to finish and collect.

Use **Pause automatic plan** or **Resume automatic plan** in Active plan. The plan icon sits beside the ongoing-action spinner and opens the planner. Its three connected steps animate in sequence while running or waiting, and stay still when paused, complete, or needing attention. It is hidden when no recipe plan is saved and respects reduced-motion preferences. Its colors indicate state: green means running or complete, blue means waiting, amber means attention is needed, and gray means paused. Its tooltip explains the state. Automatic progression requires script automation to be enabled and the game tab to be open and visible. Existing plans stay paused until you resume or save them again.

**Start next** and **Stop & collect** / **Collect completed work** remain available for manual control. Using these pauses automatic progression. Each manual button performs only its displayed action and keeps the plan. Editing saved sources or quantities also leaves progression paused until you resume. If another action replaces tracked work, a request fails, or progress cannot be confirmed, the planner stops and explains what needs attention. Purchases, combat-drop acquisition, and inventory conversions remain manual; the runner waits when these block the remaining steps.

For crafting, **Native quantity** means Ironwood's quantity control, not guaranteed output. Known base yields provide a suggestion; uncertain yields are labelled and can require your own quantity. Select **Apply quantity** (or press Enter in its field) to save an edit. For a supported recipe, a saved batch larger than the remaining requirement is reduced as owned inventory increases. Smaller custom batches stay as chosen; uncertain yields still need an explicit quantity. The panel explains any reduction and shows supplies for the displayed batch. Supplies and unique-craft limits still apply. If the next action or quantity changes, review the new choice before clicking again.

The plan recalculates from observed owned inventory, including items gained or spent elsewhere. Pending loot and projected conversion output do not count as owned. **Target satisfied** ends the automatic run and keeps the target saved; spending those items later can reveal more work, but does not restart the run. **Refresh plan** explicitly checks inventory without starting chores. An automatic run checks fresh inventory before transitions; unchanged manual blockers wait for a new observation. Reloading resumes confirmed tracked work, while an interrupted start or collection requires your review and Resume.

There is one active plan per character and game mode, saved in this browser. You can still save a single manual action in the **Single action** view; doing so replaces the recipe plan without changing current work. **Clear active plan** removes only the active plan, keeping the calculator target.
