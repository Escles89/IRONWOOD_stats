# Shopping list

On Status, choose a craftable finished item and enter a positive whole-number **Target owned quantity**. This is the total you want to own: a target of 100 with 30 already owned leaves 70 to acquire. Filter the item list by name, then save. The list contains only outputs of current main crafting recipes, excluding raw materials, runes, obsolete recipes and failure-only outputs such as burnt food. The sole recipe is selected automatically. A recipe choice is shown only if multiple recipes become available or a saved recipe needs replacing.

The card shows direct ingredient shortages and separate native resource balances such as Charcoal. Expand **Direct recipe detail** for each ingredient's per-attempt cost, required total, owned amount and missing amount. Craftable ingredients are marked as intermediate items to acquire. Recursive recipes are not included yet.

The plan uses base costs and owned stock only. Pending loot, unfinished queues, preservation savings and bonus output do not count. Recipes with variable or failure-prone output are marked uncertain. Nominal totals are a planning basis, not a promise of the finished quantity.

**Target satisfied** means the finished items are already owned. **Base materials covered** means the observed direct inputs cover a supported base recipe calculation; it does not mean crafting has occurred. Unknown data remains unknown.

Use **Edit**, **Clear** or **Refresh** as needed. The target and recipe choice are saved separately for each character and game mode in this browser. Satisfied targets stay saved and show a shortfall again after spending items. If a saved recipe disappears, choose a current one explicitly. Refresh reads the game state without starting crafting or collecting loot; an unavailable refresh retains the last observation and its age. Native recipe links open the ordinary game page without starting an action.
